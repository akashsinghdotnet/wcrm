Connect WordPress to Wcrm. Visually build custom lead capture forms with dropdowns and fields that automatically sync to your CRM dashboard.

== Description ==

Wcrm Lead Forms is the official WordPress integration for Wcrm. It allows website owners to easily build custom lead capture forms and sync them in real-time with their CRM dashboard.

**Third-Party Service Reliance**
This plugin acts as a connector to a third-party SaaS service, Wcrm (https://app.wcrm.si). When visitors submit a form on your website, the form data is securely transmitted to your Wcrm account via API webhooks. 

By using this plugin, you agree to Wcrm's Terms of Service and Privacy Policy:
* Terms of Service: https://app.wcrm.si/terms
* Privacy Policy: https://app.wcrm.si/privacy

= Features =
* 1-Click Company ID Connection
* Unlimited Custom Form Creation
* Visual Form Builder with Custom Dropdowns, Radio Buttons, Checkboxes, and Textareas
* Zero-reload AJAX submission with smooth loading animations
* 100% compatible with Gutenberg, Elementor, Divi, and all WordPress shortcodes

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/wcrm` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the Wcrm -> Settings screen to configure your Company ID.

== Frequently Asked Questions ==

= How do I find my Company ID? =
You can find your Company ID inside your Wcrm admin profile or company settings.

= Can I create multiple forms? =
Yes! You can create unlimited forms for different pages and customize the fields for each one.
